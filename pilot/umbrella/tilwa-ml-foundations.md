## U1 — Which group is the denominator? / مين المجموعة اللي بنقسم عليها؟

In a class-conditional fraction, first specify who is eligible to be in the denominator. “Of the events that actually happened, how many did we detect?” and “Of the alerts we raised, how many were real?” start from different groups. Draw the eligible group before calculating.

قبل ما تحسب أي نسبة، حدّد المجموعة اللي السؤال بيتكلم عنها. «من كل الحالات الإيجابية فعلًا، اكتشفنا كام؟» تبدأ بالحالات الإيجابية الفعلية. «من كل التنبيهات اللي طلّعها الموديل، كام تنبيه طلع صحيح؟» تبدأ بالتنبيهات. تغيير مجموعة البداية بيغيّر المقام.

## U2 — Recall and precision / الاستدعاء والإحكام

For a specified positive class, recall uses actual positives: TP / (TP + FN). Precision uses predicted positives: TP / (TP + FP). A denominator of zero means the corresponding ratio needs an explicit convention or an “undefined” label. Report the counts as well as a percentage.

عند تحديد الفئة الإيجابية، يحسب Recall الحالات التي اكتُشفت من جميع الإيجابيات الفعلية. ويحسب Precision التنبيهات الصحيحة من جميع التنبيهات الإيجابية. لو المقام صفر نعرض الوصف المعتمد للحالة؛ ما نستنتجش نسبة من غير بيانات.

Original worked example: a system produced eight alerts. Five were genuine, three were false alerts, and it missed another five genuine cases. Precision = 5/8 = 62.5%. Recall = 5/10 = 50%. In a critique task, a student can locate the first wrong step when a solution uses total alerts as the recall denominator.

مثال مستقل: لو النظام أصدر ٨ تنبيهات، منهم ٥ صح و٣ غلط، وفاته ٥ حالات حقيقية تانية، يبقى Precision بيساوي ٥ من ٨، وRecall بيساوي ٥ من ١٠. تحديد أي مجموعة دخلت المقام يوضح سبب اختلاف النسبتين.

## U3 — Choosing and justifying a metric / اختيار المقياس وتبرير القرار

A model can achieve high overall accuracy by repeatedly choosing a common class while missing a rare class. The choice of metric depends on the decision, the cost of misses and false alerts, prevalence and any review capacity. Compare two models on the same held-out cases. A defensible recommendation explains which error is more consequential in the stated setting, and what the other metric costs.

ارتفاع Accuracy ممكن يخفي مشكلة في فئة نادرة. اسأل عن تكلفة الحالة اللي الموديل فوّتها، وتكلفة الإنذار الغلط، وعدد التنبيهات اللي الفريق يقدر يراجعها. يتغيّر القرار بتغيّر السياق. حساب المقياس واختياره وتبريره أهداف تعليمية منفصلة.

## U4 — Transferring a derivative to an update / استخدام المشتقة في خطوة تحديث

For a scalar differentiable loss and a small positive learning rate, gradient descent updates a weight by subtracting the step size times its local derivative. At a positive derivative a sufficiently small negative change in the weight can reduce loss locally. Computing a derivative and interpreting the direction of a step are separate observable skills.

لو هدفنا نقلّل دالة خسارة قابلة للاشتقاق في متغير واحد، بنطرح حاصل ضرب معدل تعلّم موجب في المشتقة المحلية من الوزن الحالي. لو المشتقة موجبة فالتحرك بمقدار صغير ناحية القيم الأقل قد يقلّل الخسارة محليًا. معرفة اشتقاق الدالة لوحدها لا تثبت إن الطالب بيعرف يختار اتجاه التحديث.

## U5 — Conditional probability in classification / الاحتمال الشرطي في التصنيف

A conditional probability describes an event within a specified reference group. For categorical Naïve Bayes, the likelihood for a feature value within a class is estimated from the training examples in that class, with an explicit smoothing rule where relevant. The usual model factorizes the features conditional on the class. A Python implementation is one practice setting; the objective of interpreting a class-conditional frequency can also be assessed from a small table.

الاحتمال الشرطي بيربط الحدث بمجموعة مرجعية محددة. في Naïve Bayes للفئات الوصفية، بنقدّر احتمال قيمة الخاصية من أمثلة التدريب داخل الفئة، مع تطبيق قاعدة التنعيم المعتمدة عند الحاجة. استقلال الخصائص هنا افتراض مشروط بالفئة. الطالب يقدر يفسّر جدول تكرارات يدويًا حتى لو لسه ماكتبش كود Python.

## U6 — AI, ML and neighboring disciplines / الذكاء الاصطناعي وتعلّم الآلة والتخصصات المرتبطة

Artificial intelligence (AI) concerns systems performing tasks associated with intelligent behavior. Machine learning (ML) develops behavior from examples or experience; a learning algorithm specifies how that learning proceeds. Deep learning is an ML family using multilayer representations, not a supervision category that excludes supervised learning. Statistics supports inference from data, applied mathematics supplies quantitative models, computer science supplies algorithms, and software engineering supports reliable implementations. Data mining concerns finding useful patterns in data. Autonomous systems act with some degree of independent control; autonomy does not prove that a system uses ML. A topic named in an overview is an orientation label, not evidence that its methods have been taught.

يهتم الذكاء الاصطناعي بأنظمة تؤدي مهام مرتبطة بالسلوك الذكي. يطوّر تعلّم الآلة السلوك من الأمثلة أو الخبرة، وتحدد خوارزمية التعلّم طريقة ذلك. التعلّم العميق عائلة داخل تعلّم الآلة تستخدم تمثيلات متعددة الطبقات، وليس نوع إشراف يستبعد التعلّم الخاضع للإشراف. يدعم الإحصاء الاستدلال من البيانات، وتوفر الرياضيات التطبيقية النماذج الكمية، وعلوم الحاسب الخوارزميات، وهندسة البرمجيات التنفيذ الموثوق. يبحث تنقيب البيانات عن أنماط مفيدة. تعمل الأنظمة المستقلة بدرجة من التحكم الذاتي؛ ولا يثبت الاستقلال أنها تستخدم تعلّم الآلة. ذكر تخصص بالاسم لا يعني أن طرقه قد شُرحت.

## U7 — Data, features, targets and source formats / البيانات والسمات والأهداف وأشكال المصادر

A feature is an input attribute; a target is the outcome to predict. A feature matrix X has one example per row and one feature per column; a target vector y must preserve the same row alignment. Labeled data has target information for the task; unlabeled data lacks those task labels. Regression calls the response the dependent variable and predictors independent variables; that name alone does not assert statistical independence. Records store observations, metadata describes data or its context, and documents contain content that may need extraction. Unstructured data lacks the fixed table organization expected by a particular model; it still has a representation. Changing row order in X without the matching change in y corrupts the training pairs.

السمة خاصية مدخلة، والهدف هو الناتج المراد التنبؤ به. تضم مصفوفة السمات X مثالاً في كل صف وسمة في كل عمود، ويجب أن يحافظ متجه الأهداف y على ترتيب الصفوف نفسه. تحمل البيانات الموسومة أهداف المهمة، بينما تفتقر البيانات غير الموسومة إلى تلك الوسوم. يُسمّى ناتج الانحدار المتغيّر التابع ومدخلاته متغيرات مستقلة؛ التسمية وحدها لا تثبت استقلالاً إحصائياً. تخزن السجلات المشاهدات، وتصف البيانات الوصفية البيانات أو سياقها، وتحمل الوثائق محتوى قد يحتاج إلى استخراج. لا تتبع البيانات غير المهيكلة تنظيم الجدول الذي يتوقعه نموذج معين، لكنها ليست بلا تمثيل. تغيير ترتيب صفوف X دون تغيير y المقابل يفسد اقتران الأمثلة بأهدافها.

## U8 — The model lifecycle and human review / دورة بناء النموذج والمراجعة البشرية

Problem framing specifies the decision, population and success criterion. Explicit rule programming writes decision rules directly; model training instead uses a learning algorithm and data to fit behavior. A practical ML workflow includes preprocessing, training, evaluation, error analysis and deployment. Error analysis asks which cases failed and why; model inspection can improve human understanding of the problem. Inference applies a fitted model to a new case, which is different from training it. A human expert may review predictions and the evidence supporting them. Evaluating, revising and launching are process steps, not proof that one learner skill is a mandatory prerequisite for another. Final evaluation must remain separate from iterative development.

تحدد صياغة المشكلة القرار والمجتمع المستهدف ومعيار النجاح. تكتب البرمجة بقواعد صريحة قواعد القرار مباشرة، بينما يستخدم تدريب النموذج خوارزمية وبيانات لتقدير السلوك. تضم دورة تعلّم الآلة المعالجة المسبقة والتدريب والتقييم وتحليل الأخطاء والنشر. يسأل تحليل الأخطاء عن الحالات التي أخفقت وأسبابها، وقد يحسن فحص النموذج فهم الإنسان للمشكلة. يطبق الاستدلال نموذجاً مدرَّباً على حالة جديدة؛ وهو مختلف عن تدريبه. يمكن لخبير بشري مراجعة التنبؤ والأدلة المؤيدة له. التقييم والتعديل والإطلاق خطوات عمل، ولا تثبت وحدها متطلبات تعليمية إلزامية بين مهارات الطالب. يجب فصل التقييم النهائي عن التطوير المتكرر.

## U9 — Application names and their limits / أسماء التطبيقات وحدود دلالتها

Image recognition interprets visual inputs; speech recognition maps speech to a useful representation such as text; machine translation transfers meaning between languages. Medical diagnosis and online fraud detection can use predictions as decision support. Stock-market trading, virtual personal assistants, spam and malware filtering, autonomous driving, product recommender systems and traffic prediction are further application settings. Text classification assigns labels to documents, including spam or topic categories. These names do not specify a particular algorithm, dataset, achieved accuracy or authorized deployment. Define inputs, targets, errors and human review for each setting before evaluating a model. A stock forecast is not a guarantee of profit, and a diagnostic prediction is not independent clinical authority.

يفسر التعرّف على الصور المدخلات المرئية، ويحوّل التعرّف على الكلام الصوت إلى تمثيل مفيد مثل النص، وتنقل الترجمة الآلية المعنى بين اللغات. قد يستخدم التشخيص الطبي واكتشاف الاحتيال عبر الإنترنت التنبؤات لمساندة القرار. تشمل التطبيقات أيضاً التداول في سوق الأسهم والمساعدات الشخصية الافتراضية وترشيح الرسائل المزعجة والبرمجيات الخبيثة والقيادة الذاتية وأنظمة توصية المنتجات والتنبؤ بحركة المرور. يمنح تصنيف النصوص الوثائق وسوماً مثل الرسائل المزعجة أو الموضوعات. لا تحدد هذه الأسماء خوارزمية أو مجموعة بيانات أو دقة محققة أو صلاحية نشر. يجب تحديد المدخلات والأهداف والأخطاء والمراجعة البشرية في كل سياق. لا يضمن تنبؤ السوق الربح، ولا يشكل التنبؤ التشخيصي سلطة طبية مستقلة.

## U10 — Supervision and prediction tasks / الإشراف ومهام التنبؤ

Supervised learning uses examples with known targets. Classification predicts class labels; regression predicts numeric responses. Binary classification selects one of two classes, multiclass classification selects one of several mutually exclusive classes, and multilabel classification permits several labels for the same example. “Cat and outdoor” is multilabel; “one of cat, dog or bird” is multiclass. A decision boundary separates predicted regions in feature space. Logistic regression is a classifier family despite its name; support vector machines are another model family used for classification and other tasks. Naming these families does not establish their detailed optimization methods. A continuous score and its thresholded class label are different outputs.

يستخدم التعلّم الخاضع للإشراف أمثلة ذات أهداف معروفة. يتنبأ التصنيف بوسوم الفئات، ويتنبأ الانحدار بقيم عددية. يختار التصنيف الثنائي فئة من اثنتين، ويختار متعدد الفئات فئة واحدة من عدة فئات متنافية، ويسمح متعدد الوسوم بأكثر من وسم للمثال نفسه. «قطة وخارج المنزل» مثال متعدد الوسوم، و«واحد من قطة أو كلب أو طائر» متعدد الفئات. يفصل حد القرار بين مناطق التنبؤ في فضاء السمات. الانحدار اللوجستي عائلة للتصنيف رغم اسمه، وآلات المتجهات الداعمة عائلة أخرى تُستخدم للتصنيف ومهام أخرى. ذكر العائلات لا يشرح طرق تحسينها التفصيلية. تختلف الدرجة المستمرة عن وسم الفئة الناتج بعد تطبيق عتبة.

## U11 — Patterns without target labels / الأنماط دون وسوم الأهداف

Unsupervised learning searches for structure without the task's target labels. Clustering groups observations using a chosen similarity notion; closeness within a cluster is meaningful only relative to its representation and distance. Anomaly detection seeks unusual observations compared with a reference pattern. Some anomaly detectors use supervised information, so the task name alone does not fix its learning mode. Association analysis describes recurring relationships among items; an association is not proof of causation. A visually plausible group, anomaly or association still needs an interpretation consistent with the data and intended question.

يبحث التعلّم غير الخاضع للإشراف عن بنية دون وسوم أهداف المهمة. يجمع التجميع المشاهدات وفق مفهوم تشابه محدد؛ ولا يكون التقارب داخل المجموعة ذا معنى إلا بالنسبة للتمثيل والمسافة المستخدمين. يبحث اكتشاف الشذوذ عن مشاهدات غير معتادة مقارنة بنمط مرجعي. تستخدم بعض كواشف الشذوذ معلومات خاضعة للإشراف، لذلك لا يحدد اسم المهمة نمط التعلّم وحده. يصف تحليل الارتباطات بين العناصر علاقات متكررة؛ ولا يثبت الارتباط السببية. تحتاج المجموعة أو الحالة الشاذة أو العلاقة التي تبدو مقنعة بصرياً إلى تفسير يتفق مع البيانات والسؤال المقصود.

## U12 — Semi-supervision and pseudo-labels / التعلّم شبه الخاضع للإشراف والوسوم الزائفة

Semi-supervised learning combines information from labeled and unlabeled examples. One approach is pseudo-labeling: fit an initial model on known labels, predict provisional labels for selected unlabeled examples, then train with the known and provisional labels. A pseudo-label is a model guess, not new ground truth. Wrong guesses can reinforce themselves, so selection rules and evaluation remain important. This workflow illustrates one semi-supervised method; it is not a requirement that every such method must manufacture labels in exactly this way.

يجمع التعلّم شبه الخاضع للإشراف معلومات من أمثلة موسومة وأخرى غير موسومة. من أساليبه الوسم الزائف: ندرّب نموذجاً أولياً على الوسوم المعروفة، ثم نتنبأ بوسوم مؤقتة لأمثلة مختارة غير موسومة، ثم ندرّب باستخدام النوعين. الوسم الزائف تخمين من النموذج وليس حقيقة مرجعية جديدة. قد تعزز التخمينات الخاطئة نفسها، لذا تهم قواعد الاختيار والتقييم. يشرح هذا المسار طريقة واحدة، ولا يلزم كل أسلوب شبه خاضع للإشراف بتوليد الوسوم بالطريقة نفسها.

## U13 — Agent, environment and reward / الوكيل والبيئة والمكافأة

In reinforcement learning, an agent chooses actions in an environment. The environment has a state; an observation is the information available to the agent and need not reveal the full state. A policy determines how actions are selected from available information. Reward is feedback used to evaluate behavior, and exploration tries actions to learn about their consequences. The cycle is observe, select and execute an action, receive feedback and update the learning procedure. Reward may be delayed or noisy; it need not mark every action simply right or wrong. Seeking a high-return policy is an objective, not a guarantee that any procedure reaches an optimal policy.

في التعلّم المعزّز يختار الوكيل أفعالاً داخل بيئة. للبيئة حالة، والملاحظة هي المعلومات المتاحة للوكيل وقد لا تكشف الحالة كاملة. تحدد السياسة كيفية اختيار الأفعال من المعلومات المتاحة. المكافأة تغذية راجعة لتقييم السلوك، ويجرب الاستكشاف أفعالاً للتعلّم عن نتائجها. تتضمن الدورة الملاحظة واختيار الفعل وتنفيذه وتلقي التغذية الراجعة وتحديث إجراء التعلّم. قد تتأخر المكافأة أو تحمل ضوضاء؛ ولا يلزم أن تصنّف كل فعل ببساطة إلى صحيح أو خاطئ. البحث عن سياسة ذات عائد مرتفع هدف، وليس ضماناً لوصول أي إجراء إلى السياسة المثلى.

## U14 — Neural layers and learned representations / الطبقات العصبية والتمثيلات المتعلَّمة

An artificial neural network connects computational units. Its input layer receives features, hidden layers transform intermediate representations, and its output layer produces the task output. A deep network uses multiple processing layers to learn representations; “deep” is not equivalent to “unlabeled.” Developers choose architectures and training procedures, while training commonly learns numerical parameters. Architecture search is a separate possible procedure, not an inherent requirement. Deep networks can learn with labeled, unlabeled or reward-based information. A layer diagram shows connectivity and depth; it does not by itself prove a model's accuracy or explain the numerical update rule.

تربط الشبكة العصبية الاصطناعية وحدات حسابية. تستقبل طبقة الإدخال السمات، وتحول الطبقات المخفية التمثيلات الوسيطة، وتنتج طبقة الإخراج ناتج المهمة. تستخدم الشبكة العميقة طبقات معالجة متعددة لتعلّم التمثيلات؛ ولا يعني «عميق» أن البيانات غير موسومة. يختار المطورون البنى وإجراءات التدريب، ويتعلم التدريب عادة معاملات عددية. البحث عن البنية إجراء ممكن منفصل وليس شرطاً ملازماً. قد تتعلم الشبكات العميقة بمعلومات موسومة أو غير موسومة أو قائمة على المكافأة. يوضح رسم الطبقات الاتصال والعمق، لكنه لا يثبت دقة النموذج أو يشرح وحده قاعدة التحديث العددي.

## U15 — Batch, online learning and changing data / التعلّم الدفعي والمتتابع وتغيّر البيانات

Batch learning fits a model from an available training collection; the deployed model may then perform inference without further updates. Online learning incrementally updates an existing model as examples or small batches arrive in a data stream. Online describes the update pattern, not necessarily an internet connection. Retraining replaces or refits a model using refreshed data. Data drift is a change in input-data distribution; concept drift concerns a change in the relationship between inputs and outcomes. Model performance decay is an observed degradation, not a synonym for every distribution shift. Monitor relevant evidence before deciding that a change requires retraining.

يدرّب التعلّم الدفعي نموذجاً من مجموعة تدريب متاحة، وقد ينفذ النموذج المنشور الاستدلال لاحقاً دون تحديثات إضافية. يحدّث التعلّم المتتابع نموذجاً موجوداً تدريجياً مع وصول أمثلة أو دفعات صغيرة في تدفّق بيانات. تصف كلمة Online نمط التحديث ولا تستلزم اتصالاً بالإنترنت. تعيد إعادة التدريب تقدير النموذج أو استبداله ببيانات محدثة. انجراف البيانات تغيّر في توزيع المدخلات، وانجراف المفهوم تغيّر في العلاقة بين المدخلات والنواتج. تدهور أداء النموذج انخفاض مُلاحظ وليس مرادفاً لكل تغيّر في التوزيع. تُراقَب الأدلة المناسبة قبل تقرير أن التغيّر يستلزم إعادة التدريب.

## U16 — Update size, memory and adaptation / حجم التحديث والذاكرة والتكيّف

A mini-batch is a small group used in one learning step; mini-batches also appear in offline training. Out-of-core learning processes parts of a dataset that cannot all fit in main memory. A learning rate controls update size in many training algorithms; larger steps can adapt faster but may be unstable or overwrite useful earlier behavior. The stability–plasticity dilemma balances retaining previous knowledge with adapting to new information. Forgetting previously learned knowledge is a possible failure, not a mandatory result of every update. Selective data addition chooses which new examples enter learning. Its rule must be evaluated for accuracy, representativeness and retained knowledge.

الدفعة المصغّرة مجموعة صغيرة تُستخدم في خطوة تعلّم؛ وتظهر أيضاً في التدريب غير المتتابع. يعالج التعلّم خارج الذاكرة الرئيسية أجزاءً من بيانات لا تتسع لها الذاكرة دفعة واحدة. يتحكم معدّل التعلّم في حجم التحديث في خوارزميات كثيرة؛ قد تتكيف الخطوات الأكبر أسرع لكنها قد تصبح غير مستقرة أو تمحو سلوكاً مفيداً سابقاً. توازن معضلة الثبات والمرونة الاحتفاظ بالمعرفة السابقة مع التكيّف مع معلومات جديدة. نسيان المعرفة السابقة إخفاق محتمل وليس نتيجة حتمية لكل تحديث. تختار الإضافة الانتقائية للبيانات الأمثلة الجديدة الداخلة في التعلّم، ويجب تقييم أثرها في الدقة والتمثيل والاحتفاظ بالمعرفة.

## U17 — Samples, quantity and data quality / العيّنات والكمية وجودة البيانات

A target population describes the cases about which a claim is intended; a sample contains the observed cases. Sample representativeness matters because new cases may differ from training examples. More data does not automatically repair a biased sample, and there is no universal minimum of thousands or millions of rows. Data errors are incorrect records; measurement noise is unwanted variability in recorded values. An outlier is unusual relative to a reference pattern and may be valid. Cleaning and outlier handling require a documented reason: investigate, correct when justified, or retain rather than automatically delete. Quality includes accuracy, consistency and fitness for the task, not merely tidy formatting.

يصف المجتمع المستهدف الحالات المقصودة بالاستنتاج، وتضم العينة الحالات المرصودة. يهم تمثيل العينة لأن الحالات الجديدة قد تختلف عن أمثلة التدريب. لا تصلح زيادة البيانات تلقائياً عينة منحازة، ولا يوجد حد أدنى عام بآلاف أو ملايين الصفوف. أخطاء البيانات سجلات غير صحيحة، وضوضاء القياس تباين غير مرغوب في القيم المسجلة. القيمة المتطرفة غير معتادة مقارنة بنمط مرجعي وقد تكون صحيحة. يحتاج التنظيف ومعالجة القيم المتطرفة إلى سبب موثق: نفحص ونصحح عند وجود مبرر أو نحتفظ بالحالة بدلاً من حذفها تلقائياً. تشمل الجودة الدقة والاتساق وملاءمة المهمة، وليس مجرد ترتيب الشكل.

## U18 — Feature engineering and its tools / هندسة السمات وأدواتها

Feature engineering turns available data into useful model inputs. Feature selection keeps a subset of existing features; feature extraction transforms inputs into a new representation; feature creation may derive a new attribute or collect new measurements. Irrelevant features need not improve prediction. Selecting and merging data sources must preserve record identity; transformations and scaling change representations and can alter distance-based results. Pandas supports tabular manipulation, NumPy supports numerical arrays, Featuretools supports automated feature construction, scikit-learn provides preprocessing and model tools, and TensorFlow Transform supports transformation pipelines. These are orientation descriptions, not proof that a particular API was taught. Learn data-dependent transformations using training data only.

تحوّل هندسة السمات البيانات المتاحة إلى مدخلات مفيدة للنموذج. يحتفظ اختيار السمات بمجموعة من السمات الموجودة، ويحوّل استخراج السمات المدخلات إلى تمثيل جديد، وقد ينشئ إنشاء السمات خاصية مشتقة أو يجمع قياسات جديدة. لا تحسن السمات غير ذات الصلة التنبؤ بالضرورة. يجب أن يحافظ اختيار المصادر ودمجها على هوية السجلات؛ وتغيّر التحويلات والتحجيم التمثيل وقد تؤثر في النتائج المبنية على المسافات. تدعم Pandas معالجة الجداول، وNumPy المصفوفات العددية، وFeaturetools بناء السمات آلياً، وتوفر scikit-learn أدوات المعالجة والنماذج، ويدعم TensorFlow Transform مسارات التحويل. هذه أوصاف تمهيدية وليست دليلاً على تدريس واجهة معينة. تُتعلّم التحويلات المعتمدة على البيانات من بيانات التدريب فقط.

## U19 — Fit, complexity and generalization / الملاءمة والتعقيد والتعميم

Generalization is performance on relevant unseen cases. Overfitting captures training-specific detail that does not transfer; underfitting misses important structure even in training data. An appropriate fit balances useful structure and sensitivity to incidental variation. Model complexity influences this balance but does not determine performance alone. Bias describes systematic error under a learning setup; variance describes sensitivity to the particular training sample. Increasing flexibility can reduce bias while increasing variance, but this is a tendency requiring evaluation. A wiggly decision boundary is an illustration, not a measured test score. A data split permits assessment of overfitting; splitting alone does not prevent it.

التعميم هو الأداء على حالات جديدة ذات صلة. يلتقط فرط التكيّف تفاصيل خاصة بالتدريب لا تنتقل إلى الحالات الجديدة، بينما يفشل قصور التكيّف في التقاط بنية مهمة حتى في التدريب. توازن الملاءمة المناسبة البنية المفيدة والحساسية للتغيرات العرضية. يؤثر تعقيد النموذج في هذا التوازن لكنه لا يحدد الأداء وحده. يصف التحيز الخطأ المنهجي ضمن إعداد تعلّم، ويصف التباين الحساسية لعينة التدريب المستخدمة. قد تقلل المرونة التحيز وتزيد التباين، لكن ذلك اتجاه يحتاج إلى تقييم. حد القرار المتعرج رسم توضيحي وليس نتيجة اختبار مقاسة. يسمح تقسيم البيانات بتقييم فرط التكيّف ولا يمنعه وحده.

## U20 — Predictive and descriptive questions / الأسئلة التنبّؤية والوصفية

Predictive analysis estimates an unknown target from available information; the target need not be later in calendar time. Classification, regression and forecasting are predictive tasks. Descriptive analysis organizes what is observed through clustering, association analysis or data summarization. Tabular summarization shows values or counts in tables; data visualization uses graphs to communicate patterns. A time series is an ordered sequence indexed by time. Earlier observations may help predict later ones, but do not determine them with certainty. These categories organize questions and can overlap within one project. Choose summaries, axes, units and reference groups that match the question.

يقدّر التحليل التنبّؤي هدفاً غير معروف من معلومات متاحة، ولا يلزم أن يكون الهدف لاحقاً زمنياً. التصنيف والانحدار والتنبؤ المستقبلي مهام تنبّؤية. ينظم التحليل الوصفي ما شوهد بالتجميع أو تحليل الارتباطات أو تلخيص البيانات. يعرض التلخيص الجدولي قيماً أو أعداداً في جداول، ويستخدم تصوّر البيانات الرسوم لنقل الأنماط. السلسلة الزمنية تسلسل مرتب بمؤشر زمني. قد تساعد المشاهدات السابقة على توقع اللاحقة لكنها لا تحددها يقيناً. تنظم هذه الفئات الأسئلة وقد تتداخل في مشروع واحد. يجب اختيار الملخصات والمحاور والوحدات والمجموعات المرجعية بما يوافق السؤال.

## U21 — Training, validation and a final test / التدريب والتحقق والاختبار النهائي

Training data fits model parameters. Validation data compares development choices such as hyperparameters and candidate models. An independent final test estimates performance after those choices are fixed. A holdout is a reserved subset; its role must be named explicitly. Supervised test targets exist for the evaluator to compare with predictions but are hidden from fitting and tuning. “Unseen” does not mean “ground truth does not exist.” Use disjoint partitions with no duplicated case crossing a prohibited boundary. A learned weight is a parameter; neighbor count or maximum tree depth is a hyperparameter. Do not keep revising the selected model against the final test result.

تُستخدم بيانات التدريب لتقدير معاملات النموذج. وتقارن بيانات التحقق اختيارات التطوير مثل المعاملات الفائقة والنماذج المرشحة. يقدّر الاختبار النهائي المستقل الأداء بعد تثبيت تلك الاختيارات. المجموعة المحجوزة جزء محفوظ يجب تحديد دوره صراحة. توجد أهداف الاختبار الخاضع للإشراف لدى المقيّم لمقارنتها بالتنبؤات، لكنها تُحجب عن التدريب والضبط. لا تعني «غير مشاهدة» أن الحقيقة المرجعية غير موجودة. تُستخدم أقسام منفصلة دون عبور الحالة المكررة لحد محظور. الوزن المتعلَّم معامل، وعدد الجيران أو عمق الشجرة الأقصى معامل فائق. لا ينبغي مواصلة تعديل النموذج المختار على نتيجة الاختبار النهائي.

## U22 — Reproducible splitting and aligned arrays / تقسيم قابل لإعادة الإنتاج ومصفوفات متحاذية

In Python, NumPy can store X as an n-by-d feature array and y as n matching targets. scikit-learn's train_test_split(X, y, ...) splits them together so rows remain paired. A fixed random_state, such as 42, makes that randomized procedure reproducible under the same inputs and implementation; it does not prove an unbiased split. Fractions are converted to integer sample counts: with eight examples, train_size=0.8 selects six training examples in this interface and leaves two for testing, rather than creating 6.4 examples. With five examples and test_size=0.4, two are held out. Report actual counts. Random row splitting may be inappropriate for linked people or future-time prediction; the split must match the question.

يمكن في Python تخزين X بمصفوفة NumPy ذات n صفوف وd سمات، وy بعدد n من الأهداف المقابلة. تقسم دالة train_test_split(X, y, ...) في scikit-learn المصفوفتين معاً فتحافظ على اقتران الصفوف. يجعل random_state ثابت مثل 42 الإجراء العشوائي قابلاً لإعادة الإنتاج مع المدخلات والتنفيذ نفسيهما، لكنه لا يثبت خلو التقسيم من الانحياز. تتحول النسب إلى أعداد صحيحة: عند ثمانية أمثلة تختار train_size=0.8 ستة للتدريب وتترك اثنين للاختبار في هذه الواجهة، بدلاً من إنشاء 6.4 أمثلة. وعند خمسة أمثلة وtest_size=0.4 يُحجز مثالان. يجب عرض الأعداد الفعلية. قد لا يناسب التقسيم العشوائي للصفوف بيانات الأشخاص المترابطة أو توقع المستقبل؛ ويجب أن يوافق التقسيم السؤال.

## U23 — Cross-validation and adaptive selection / التحقق المتقاطع والاختيار المتكرر

In v-fold cross-validation, divide development data into v folds. Fit on v−1 folds and validate on the remaining fold, rotating until each fold has served as validation. Compare appropriately aggregated validation scores across candidates, while keeping a final test partition separate. Training scores describe fitted data; validation scores support selection; the final test score answers a different, final-evaluation question. Repeatedly choosing models against the same validation results can overfit the development process to them. The number of folds v is distinct from the number of KNN neighbors k. Every data-dependent preprocessing or resampling step belongs inside the training portion of each fold.

في التحقق المتقاطع ذي v طيات تُقسَّم بيانات التطوير إلى v أقسام. ندرّب على v−1 طية ونتحقق على المتبقية، ثم نبدّل حتى تستخدم كل طية للتحقق. نقارن درجات تحقق مجمعة بطريقة مناسبة بين المرشحين، مع إبقاء قسم الاختبار النهائي منفصلاً. تصف درجات التدريب البيانات الملائمة، وتدعم درجات التحقق الاختيار، وتجيب درجة الاختبار النهائي عن سؤال تقييم أخير مختلف. قد يفرط التطوير في التكيّف مع نتائج التحقق عند تكرار الاختيار عليها. يختلف عدد الطيات v عن عدد جيران KNN المسمّى k. يجب تنفيذ كل خطوة معالجة أو إعادة عينات تعتمد على البيانات داخل جزء التدريب من كل طية.

## U24 — Fit preprocessing once in the allowed partition / تعلّم المعالجة داخل القسم المسموح

A transformation can have a fitting step and an applying step. For example, estimate scaling values from training data, then apply the same learned transformation to validation, test and future inputs. Estimating those values from all data lets held-out information influence development. Cleaning rules, feature extraction and missing-value treatment need the same scope check. Consistent preprocessing means compatible feature meaning and transformation at training and prediction time; it does not authorize learning new preprocessing parameters from a final test set. Pipelines help repeat the correct order but do not automatically make an inappropriate split valid.

قد يتضمن التحويل خطوة لتعلّم معاملاته وأخرى لتطبيقه. مثلاً نقدّر قيم التحجيم من بيانات التدريب ثم نطبق التحويل المتعلَّم نفسه على التحقق والاختبار والمدخلات المستقبلية. يسمح تقدير القيم من جميع البيانات بتأثير المعلومات المحجوزة في التطوير. تحتاج قواعد التنظيف واستخراج السمات ومعالجة القيم المفقودة إلى فحص النطاق نفسه. يعني اتساق المعالجة توافق معاني السمات وتحويلها وقت التدريب والتنبؤ، ولا يجيز تعلّم معاملات معالجة جديدة من الاختبار النهائي. تساعد مسارات المعالجة في تكرار الترتيب الصحيح لكنها لا تجعل التقسيم غير المناسب صالحاً تلقائياً.

## U25 — Imbalance and the majority baseline / اختلال التوازن وخط أساس الفئة الغالبة

Class imbalance means unequal class frequencies. The majority class is more common and a minority class less common in the stated population or sample. A learner may favor the majority and still obtain high accuracy. If only 1% of cases are positive, always predicting negative yields 99% accuracy and zero recall for the positive class. Prevalence is the actual positive fraction, not the fraction of alerts. Balancing a training sample is a modeling choice, not proof that deployment prevalence is 50%. Evaluate against the intended population and report class-sensitive measures as well as the majority-class baseline.

اختلال توازن الفئات اختلاف تكراراتها. الفئة الغالبة أكثر شيوعاً، والنادرة أقل شيوعاً داخل المجتمع أو العينة المحددة. قد يميل المتعلم للفئة الغالبة ويحقق دقة كلية مرتفعة. إذا كانت الإيجابيات 1% فقط، فإن التنبؤ دائماً بالسالب يحقق دقة 99% واستدعاء صفرياً للإيجابيات. الانتشار هو نسبة الإيجابيات الفعلية وليس نسبة التنبيهات. موازنة عينة التدريب اختيار نمذجة، ولا تثبت أن انتشار الفئة في الاستخدام يساوي 50%. ينبغي التقييم بالنسبة للمجتمع المقصود وعرض مقاييس حساسة للفئات مع خط أساس الفئة الغالبة.

## U26 — Resampling and unequal error costs / إعادة أخذ العينات وتفاوت تكلفة الخطأ

Random undersampling removes selected majority examples and may discard useful information. Random oversampling repeats selected minority examples, usually by sampling with replacement; duplication adds weight, not new independent evidence. Repeated copies across training and validation can create misleading evaluation. The oversampling ratio specifies a target count or class proportion and must be stated explicitly. Resample only the allowed training portion; preserve the intended evaluation distribution. Cost-sensitive learning instead changes how errors contribute to training loss, for example assigning a larger weight to missed positives. Resampling and loss weights may alter decisions, but neither guarantees better deployment performance.

يحذف خفض العينات العشوائي أمثلة مختارة من الفئة الغالبة وقد يفقد معلومات مفيدة. تكرر زيادة العينات العشوائية أمثلة من الفئة النادرة، عادة بالسحب مع الإرجاع؛ تضيف النسخ وزناً لا أدلة مستقلة جديدة. قد يعطي تكرار النسخ بين التدريب والتحقق تقييماً مضللاً. تحدد نسبة زيادة العينات عدداً مستهدفاً أو نسبة فئة ويجب التصريح بها. تُعاد العينات داخل جزء التدريب المسموح فقط مع الحفاظ على توزيع التقييم المقصود. يغيّر التعلّم الحساس للتكلفة إسهام الأخطاء في خسارة التدريب، كإعطاء وزن أكبر للإيجابيات التي لم تُكتشف. قد تغير إعادة العينات والأوزان القرارات، لكن أياً منهما لا يضمن تحسن الاستخدام الفعلي.

## U27 — SMOTE as interpolation / SMOTE بوصفها استيفاءً

SMOTE means Synthetic Minority Oversampling Technique. In the usual numeric-feature construction, choose a minority example x and a nearby minority example z, then form x_new = x + λ(z−x), with 0 ≤ λ ≤ 1. This is a point on the segment between the two examples, not a copied observation. If x=(2,4), z=(6,8) and λ=0.25, then x_new=(3,5). Choose minority neighbors and the desired oversampling amount within the training partition. Interpolating arbitrary category codes is not automatically meaningful, and synthetic points can cross unsuitable regions. Generated data remains a modeling choice, not newly observed ground truth.

تعني SMOTE تقنية زيادة عينات الفئة النادرة اصطناعياً. في البناء المعتاد للسمات العددية نختار مثالاً نادراً x وجاراً نادراً z، ثم نحسب x_new = x + λ(z−x)، حيث 0 ≤ λ ≤ 1. تقع النقطة على القطعة بين المثالين وليست نسخة من مشاهدة. إذا كان x=(2,4) وz=(6,8) وλ=0.25، تصبح النقطة الجديدة (3,5). يُختار الجيران ومقدار الزيادة داخل قسم التدريب. لا يكون استيفاء أكواد الفئات الاعتباطية ذا معنى تلقائياً، وقد تعبر النقاط الاصطناعية مناطق غير مناسبة. تبقى البيانات المولدة اختياراً للنمذجة وليست حقيقة رُصدت حديثاً.

## U28 — Read the confusion matrix before dividing / قراءة مصفوفة الالتباس قبل القسمة

First declare the positive class and the orientation of the table. With rows actual and columns predicted: TP is actual positive/predicted positive; FN is actual positive/predicted negative; FP is actual negative/predicted positive; TN is actual negative/predicted negative. Actual positives total TP+FN; predicted positives total TP+FP. These are different reference groups. “Type I” and “Type II” error names are sometimes associated with false positives and false negatives, but the hypothesis and positive class must be specified. Check that all cells sum to the dataset total and row totals agree with any stated class counts. A contradiction cannot be repaired by silently choosing a preferred total.

نحدد أولاً الفئة الإيجابية واتجاه الجدول. عندما تكون الصفوف للحقيقة والأعمدة للتنبؤ: TP إيجابي فعلي ومتنبأ به، وFN إيجابي فعلي متنبأ به سالباً، وFP سلبي فعلي متنبأ به إيجاباً، وTN سلبي فعلي ومتنبأ به. مجموع الإيجابيات الفعلية TP+FN، ومجموع التنبيهات الإيجابية TP+FP؛ وهما مجموعتان مختلفتان. ترتبط تسميتا خطأ النوع الأول والثاني أحياناً بالإيجابي الكاذب والسلبي الكاذب، لكن يلزم تحديد الفرضية والفئة الإيجابية. يجب أن يساوي مجموع الخلايا عدد الحالات وأن توافق مجاميع الصفوف أعداد الفئات المعلنة. لا يُصلح التعارض باختيار مجموع مفضل ضمنياً.

## U29 — Metrics and why recall can be 60% / المقاييس ولماذا قد يساوي الاستدعاء 60%

For a specified positive class, precision = TP/(TP+FP), recall = TP/(TP+FN), accuracy = (TP+TN)/N, and classification error rate = (FP+FN)/N = 1−accuracy. F1 is the harmonic mean 2PR/(P+R), equivalently 2TP/(2TP+FP+FN) when applicable; it is not the arithmetic mean. In the reviewed CET351 fraud counts, TP=6, FN=4, FP=20 and TN=970. Recall is 6/(6+4)=60% because six of ten actual frauds were found. Precision is 6/26≈23.08%, accuracy 976/1000=97.6%, error 2.4%, and F1=12/36≈33.33%. Twenty false alerts affect precision, not the actual-positive recall denominator. State the convention whenever a metric denominator is zero; never fabricate a percentage.

عند تحديد الفئة الإيجابية: الإحكام TP/(TP+FP)، والاستدعاء TP/(TP+FN)، والدقة الكلية (TP+TN)/N، ومعدل خطأ التصنيف (FP+FN)/N أي 1−الدقة. درجة F1 متوسط توافقي يساوي 2PR/(P+R)، أو 2TP/(2TP+FP+FN) حيث تنطبق الصيغة، وليست متوسطاً حسابياً. في أعداد الاحتيال المراجعة في CET351 نجد TP=6 وFN=4 وFP=20 وTN=970. الاستدعاء 6/(6+4)=60% لأننا وجدنا ست حالات من عشر حالات احتيال فعلية. الإحكام 6/26≈23.08%، والدقة 976/1000=97.6%، والخطأ 2.4%، وF1 تساوي 12/36≈33.33%. تؤثر الإنذارات الكاذبة العشرون في الإحكام وليس في مقام الاستدعاء. تُذكر القاعدة المتبعة عند مقام صفري ولا تُختلق نسبة.

## U30 — Thresholds, metrics and defensible decisions / العتبات والمقاييس والقرارات المبررة

A decision threshold converts a score into a class decision. Lowering a positive threshold often increases both detected positives and false alerts, but exact changes depend on the scores. Metric selection should consider false-negative costs, false-positive costs, prevalence and review capacity. Precision measures the reliability of alerts; recall measures the fraction of actual positives retrieved. F1 balances these two ratios but does not encode every operational cost or reward true negatives. No universal “good F1” band proves suitability. Choose thresholds and metrics with development evidence, then evaluate the fixed policy independently. Explain the tradeoff rather than announcing that one metric always wins.

تحول عتبة القرار الدرجة إلى قرار فئة. يؤدي خفض عتبة الإيجاب غالباً إلى زيادة الإيجابيات المكتشفة والإنذارات الكاذبة معاً، لكن التغير الفعلي يعتمد على الدرجات. يراعي اختيار المقياس تكلفة الإيجابيات الفائتة والإنذارات الخاطئة وانتشار الفئة وقدرة المراجعة. يقيس الإحكام موثوقية التنبيهات، ويقيس الاستدعاء نسبة الإيجابيات الفعلية المسترجعة. توازن F1 النسبتين لكنها لا تمثل كل تكلفة تشغيلية ولا تكافئ السلبيات الصحيحة. لا يثبت نطاق عام يسمى «F1 جيدة» ملاءمة النموذج. تُختار العتبات والمقاييس بأدلة التطوير ثم تُقيَّم السياسة المثبتة مستقلاً، مع تفسير المفاضلة بدلاً من إعلان فوز مقياس دائماً.

## U31 — Distances and high-dimensional features / المسافات والسمات عالية الأبعاد

For numeric vectors x and z, Euclidean distance is √Σ_j(x_j−z_j)² and Manhattan distance is Σ_j|x_j−z_j|. Between (1,2) and (4,6), these are 5 and 7 respectively. A distance metric defines what “near” means for neighbor search; units and scaling can change the ranking. Adding many features increases computational work and can make nearby/far distinctions less useful: this is one aspect of the curse of dimensionality, not proof that every high-dimensional problem must fail. Do not treat arbitrary category codes as meaningful numeric distances without a justified representation.

للمتجهين العدديين x وz تكون المسافة الإقليدية √Σ_j(x_j−z_j)² ومسافة مانهاتن Σ_j|x_j−z_j|. بين (1,2) و(4,6) تساويان 5 و7 على الترتيب. يحدد مقياس المسافة معنى القرب في البحث عن الجيران؛ وقد تغيّر الوحدات والتحجيم ترتيبهم. تزيد السمات الكثيرة العمل الحسابي وقد تضعف التمييز بين القريب والبعيد؛ وهذا جانب من لعنة الأبعاد وليس برهاناً على إخفاق كل مسألة عالية الأبعاد. لا تُعامل أكواد الفئات الاعتباطية كمسافات عددية ذات معنى دون تمثيل مبرر.

## U32 — KNN prediction, lazy learning and ties / تنبؤ أقرب الجيران والتعلّم الكسول والتعادل

Basic K-nearest neighbors (KNN) stores labeled examples. For a query, compute distances, rank candidates, select k nearest examples, then use the most frequent class for classification or the mean target for regression. This is lazy learning: much of the work is deferred until prediction rather than iterative parameter fitting. A naive full scan costs work proportional to the number of stored examples times feature count, plus neighbor selection, and requires storage. Search methods can change this cost. A vote such as A,A,B selects A; numeric neighbors 2,5,8 average to 5. Odd k prevents equal two-class counts only for unweighted binary voting. Multiclass, weighted or equal-distance ties still need a declared policy.

تخزن خوارزمية أقرب الجيران KNN الأساسية أمثلة موسومة. للاستعلام نحسب المسافات ونرتب المرشحين ونختار أقرب k أمثلة، ثم نستخدم الفئة الأكثر تكراراً للتصنيف أو متوسط الأهداف للانحدار. هذا تعلّم كسول: يتأخر كثير من العمل إلى التنبؤ بدلاً من التقدير التكراري للمعاملات. يتطلب المسح الشامل البسيط عملاً يتناسب مع عدد الأمثلة المخزنة مضروباً في عدد السمات، إضافة لاختيار الجيران والذاكرة؛ وقد تغير طرق البحث التكلفة. تختار أصوات A,A,B الفئة A، ومتوسط الأهداف 2,5,8 هو 5. يمنع k الفردي تساوي أصوات فئتين فقط عند تصويت ثنائي غير موزون. تبقى حالات تعدد الفئات أو الأوزان أو تساوي المسافات بحاجة إلى سياسة معلنة.

## U33 — Choosing a neighbor count / اختيار عدد الجيران

The neighbor count k is a hyperparameter. Small neighborhoods can follow local detail and noise; very large ones can blur class structure. This motivates a bias–variance comparison, not a theorem that a particular k is best. Compare candidate counts by a relevant held-out or cross-validation metric. The heuristic k≈√N is only an initial candidate; with N=100 it suggests trying around 10, then validating. An elbow is a visible bend in a relevant performance curve and need not exist. A within-cluster sum-of-squares (WSS) plot from clustering is not evidence for the best KNN classification neighbor count. Never confuse neighbor count k with fold count v.

عدد الجيران k معامل فائق. قد تتبع الأحياء الصغيرة التفاصيل والضوضاء، وقد تمحو الأحياء الكبيرة جداً بنية الفئات. يدفع ذلك إلى مقارنة التحيز والتباين ولا يثبت مثالية قيمة محددة. تُقارن القيم المرشحة بمقياس مناسب على تحقق محجوز أو تحقق متقاطع. قاعدة k≈√N مجرد بداية؛ إذا كان N=100 تقترح التجربة حول 10 ثم التحقق. الكوع انحناء ظاهر في منحنى أداء ذي صلة وقد لا يوجد. منحنى مجموع مربعات المسافات داخل العناقيد WSS لا يثبت أفضل عدد جيران لتصنيف KNN. يجب عدم الخلط بين عدد الجيران k وعدد الطيات v.

## U34 — Conditional probability and Bayes terms / الاحتمال الشرطي ومصطلحات بايز

For P(B)>0, P(A|B)=P(A∩B)/P(B). Changing the reference group changes the conditional probability; P(A|B) need not equal P(B|A). For class C and features x with P(x)>0, Bayes' rule is P(C|x)=P(x|C)P(C)/P(x). The class prior P(C) describes the class before x; the class-conditional likelihood P(x|C) describes the observed features within the class; P(x) is evidence; P(C|x) is the posterior. Categorical frequency estimation counts feature values inside each class and divides by that class count. Check every feature table's class totals against the same original rows before multiplying probabilities.

عندما P(B)>0 يكون P(A|B)=P(A∩B)/P(B). يغيّر تبديل المجموعة المرجعية الاحتمال الشرطي؛ فلا يلزم تساوي P(A|B) وP(B|A). للفئة C والسمات x حيث P(x)>0 تعطي قاعدة بايز P(C|x)=P(x|C)P(C)/P(x). يصف الاحتمال القبلي P(C) الفئة قبل معرفة x، ويصف احتمال الخصائص بشرط الفئة P(x|C) السمات المرصودة داخلها، وP(x) احتمال الدليل، وP(C|x) الاحتمال اللاحق. يقدّر التكرار الفئوي الاحتمالات بعدّ قيم السمة داخل الفئة والقسمة على حجمها. يجب مطابقة مجاميع كل جدول سمات مع الصفوف الأصلية نفسها قبل ضرب الاحتمالات.

## U35 — Naive Bayes scores and normalized posteriors / درجات بايز الساذج والاحتمالات اللاحقة المطَبَّعة

Naive Bayes models features as conditionally independent given the class: P(x₁,…,x_d|C)=∏_j P(x_j|C). It does not require unconditional feature independence. Compute s_C=P(C)∏_jP(x_j|C). Maximum a posteriori (MAP) classification selects the class with largest s_C because all classes share the positive normalizer. A score is not itself a posterior: normalize with P(C|x)=s_C/Σ_K s_K when the sum is positive. Strongly correlated features can make the assumption unsuitable even when a classifier still gives useful labels. Text classification and spam filtering are possible applications, not guarantees of high accuracy. Priors, counts, smoothing and vocabulary must remain consistent.

يفترض بايز الساذج استقلال السمات مشروطاً بالفئة: P(x₁,…,x_d|C)=∏_j P(x_j|C)، ولا يفرض استقلالها غير المشروط. نحسب s_C=P(C)∏_jP(x_j|C). يختار تصنيف الاحتمال اللاحق الأكبر MAP الفئة ذات أعلى درجة لأن جميع الفئات تشترك في معامل تطبيع موجب. الدرجة ليست احتمالاً لاحقاً بذاتها: نطبّع باستخدام P(C|x)=s_C/Σ_K s_K عندما يكون المجموع موجباً. قد تجعل السمات شديدة الترابط الافتراض غير ملائم حتى إن أعطى المصنّف وسوماً مفيدة. تصنيف النصوص وترشيح الرسائل المزعجة تطبيقات ممكنة لا ضمانات دقة. يجب اتساق الاحتمالات القبلية والأعداد والتنعيم ومفردات القيم.

## U36 — Zero frequency and categorical smoothing / التكرار الصفري وتنعيم الاحتمالات الفئوية

An unobserved feature value within a class has zero unsmoothed frequency and can make that class's product score zero. It need not prevent every prediction; if all scores are zero, normalization is undefined. For one categorical feature with m defined possible values, additive smoothing estimates P(value=v|C)=(n_vC+α)/(n_C+αm), with α>0; Laplace smoothing uses α=1. If a class has four observations, three possible values and zero occurrences of one value, its Laplace estimate is 1/7. Sum over the same defined vocabulary to obtain probability one. This formula is original supplemental teaching; a slide merely naming Laplace estimation does not by itself contain the formula.

تحصل قيمة سمة لم تظهر داخل فئة على تكرار غير منعّم صفري وقد تجعل حاصل ضرب درجة الفئة صفراً. لا يمنع ذلك بالضرورة كل تنبؤ؛ لكن إذا صفرت جميع الدرجات يصبح التطبيع غير معرّف. لسمة فئوية واحدة ذات m قيم ممكنة محددة يقدّر التنعيم الجمعي P(value=v|C)=(n_vC+α)/(n_C+αm)، حيث α>0، ويستخدم لابلاس α=1. إذا ضمت الفئة أربع مشاهدات وكانت للسمة ثلاث قيم ولم تظهر إحداها، يكون تقديرها 1/7. يجب الجمع على مفردات القيم المحددة نفسها ليكون المجموع واحداً. هذه الصيغة شرح تكميلي أصلي؛ وذكر اسم لابلاس في شريحة لا يعني وجود الصيغة فيها.

## U37 — Read a decision tree as conditional tests / قراءة شجرة القرار كاختبارات شرطية

A decision tree has a root, internal decision nodes, branches, subtrees and leaves. Each internal node tests a feature; following branches reaches a leaf prediction. Recursive partitioning applies further tests to resulting subsets. A numeric split can ask income>50,000; equality follows the false branch for this strict inequality. A categorical split separates membership such as Sunny, Overcast or Rain. Missing values need a specified policy rather than an invented branch. A classification leaf often returns its most frequent class; a regression leaf may return the mean numeric target. The path describes conditional rules, while training chooses the tests from data.

تحتوي شجرة القرار على جذر وعقد قرار داخلية وفروع وأشجار فرعية وأوراق. تختبر العقدة الداخلية سمة، ويؤدي اتباع الفروع إلى تنبؤ ورقة. يطبق التقسيم المتكرر اختبارات إضافية على المجموعات الناتجة. قد يسأل التقسيم العددي income>50,000؛ فتتبع المساواة فرع الشرط غير المتحقق لأن المتباينة صارمة. يفصل التقسيم الفئوي العضوية مثل Sunny أوOvercast أوRain. تحتاج القيم المفقودة إلى سياسة محددة لا فرع مخترع. تعيد ورقة التصنيف غالباً الفئة الأكثر تكراراً، وقد تعيد ورقة الانحدار متوسط الهدف العددي. يصف المسار قواعد شرطية بينما يختار التدريب الاختبارات من البيانات.

## U38 — Impurity, splitting and stopping / عدم النقاء والتقسيم والتوقف

Node impurity describes how mixed class labels are. A pure node contains one class. Split selection compares candidate partitions using a chosen criterion; optimizing a training split does not guarantee held-out accuracy. Entropy and Gini impurity are classification criteria. For class proportions p_i, Gini=1−Σ_i p_i²; regression trees may compare reduction in target variance or squared error. These equations extend orientation-only mentions as original supplement content. Stop growing when a configured depth or sample limit is reached, when no useful split remains, or at a pure node. Pure leaves are one stopping case, not the only permissible endpoint.

يصف عدم نقاء العقدة اختلاط وسوم الفئات؛ وتحتوي العقدة النقية على فئة واحدة. يقارن اختيار التقسيم الأقسام المرشحة بمعيار محدد؛ ولا يضمن تحسين تقسيم التدريب دقة على البيانات المحجوزة. الإنتروبي وجيني معياران للتصنيف. لنسب الفئات p_i يكون Gini=1−Σ_i p_i²، وقد تقارن أشجار الانحدار خفض تباين الهدف أو الخطأ التربيعي. تضيف هذه المعادلات شرحاً أصلياً إلى الأسماء المذكورة تمهيدياً. يتوقف النمو عند بلوغ حد العمق أو العينات المقرر، أو غياب تقسيم مفيد، أو الوصول لعقدة نقية. نقاء الأوراق حالة توقف واحدة وليس النهاية المسموحة الوحيدة.

## U39 — Entropy in bits / الإنتروبي بوحدة البت

For class proportions p₁,…,p_c that sum to one, entropy is H=−Σ_i p_i log₂(p_i) bits. A pure node has H=0. Two equally common classes give H=1 bit; c equally common classes give H=log₂(c), so one is not the universal maximum. Use the limiting convention 0·log₂0=0 for the summand; log₂0 itself is undefined. For proportions 3/4 and 1/4, H≈0.811278 bits. Entropy measures uncertainty in the stated class distribution; its value does not prove that the data-generating process is deterministic or random. Specify the logarithm base and keep full precision until the final displayed result.

لنسب الفئات p₁,…,p_c التي مجموعها واحد يكون الإنتروبي H=−Σ_i p_i log₂(p_i) بوحدة البت. للعقدة النقية H=0. تعطي فئتان متساويتان H=1 بت، وتعطي c فئات متساوية H=log₂(c)، ولذلك ليس الواحد حداً أعلى عاماً. نستخدم نهاية الحد 0·log₂0=0، أما log₂0 نفسه فغير معرّف. للنسبتين 3/4 و1/4 يكون H≈0.811278 بت. يقيس الإنتروبي عدم اليقين في توزيع الفئات المحدد ولا يثبت عشوائية أو حتمية عملية توليد البيانات. يجب تحديد أساس اللوغاريتم والاحتفاظ بالدقة حتى العرض النهائي.

## U40 — Weighted entropy and information gain / الإنتروبي الموزون والكسب المعلوماتي

For a parent set S split by attribute A into S_v, post-split entropy is Σ_v (|S_v|/|S|)H(S_v). The weights are child sample fractions and sum to one when the children partition the parent. Information gain is IG(S,A)=H(S) minus that weighted entropy. Comparing unweighted child averages can select the wrong split. An original example: a balanced eight-case parent has H=1 bit; two four-case children with class counts (3,1) and (1,3) each have H≈0.811278, giving IG≈0.188722 bits. Choose the highest gain among the considered candidates when using this criterion, but do not equate training gain with independent predictive accuracy.

إذا قُسمت مجموعة أصل S بالسمة A إلى مجموعات S_v، فالإنتروبي بعد التقسيم هو Σ_v (|S_v|/|S|)H(S_v). الأوزان نسب أحجام الأبناء ومجموعها واحد عندما تقسم الأصل بالكامل. الكسب المعلوماتي IG(S,A) هو إنتروبي الأصل ناقص هذا المتوسط الموزون. قد يؤدي متوسط الأبناء غير الموزون إلى اختيار خاطئ. في مثال أصلي: لأصل متوازن من ثماني حالات H=1 بت؛ وابنان من أربع حالات لكل منهما بأعداد (3,1) و(1,3) لهما H≈0.811278، فيكون الكسب ≈0.188722 بت. نختار أعلى كسب بين المرشحين وفق هذا المعيار، دون مساواة كسب التدريب بالدقة التنبّؤية المستقلة.

## U41 — Ensembles and randomized forests / النماذج التجميعية والغابات العشوائية

Ensemble learning combines multiple model predictions. Ensemble classification combines class predictions; an ensemble can also predict numeric targets. A weak learner is comparatively limited under a specified baseline, but not every ensemble member must be weak. A random forest combines decision trees trained with randomized data sampling and feature-subset choices. Standard implementations often use bootstrap samples and random feature candidates at splits; a lecture saying “random parts” alone does not specify sampling with replacement. Diversity means differing predictions or errors, not statistical independence. Randomization and aggregation can help generalization but do not guarantee improved accuracy for every dataset.

يجمع التعلّم التجميعي تنبؤات نماذج متعددة. يجمع التصنيف التجميعي تنبؤات الفئات، وقد يتنبأ التجميع أيضاً بأهداف عددية. المتعلم الضعيف محدود نسبياً تحت خط أساس محدد، لكن ليس كل عضو في تجميع ملزماً بأن يكون ضعيفاً. تجمع الغابة العشوائية أشجار قرار مدربة بعينات بيانات واختيارات مجموعات سمات عشوائية. تستخدم تطبيقات معيارية غالباً عينات Bootstrap ومرشحي سمات عشوائيين عند التقسيم؛ لكن عبارة «أجزاء عشوائية» في محاضرة لا تحدد وحدها السحب مع الإرجاع. يعني التنوع اختلاف التنبؤات أو الأخطاء وليس الاستقلال الإحصائي. قد تحسن العشوائية والتجميع التعميم دون ضمان دقة أعلى لكل بيانات.

## U42 — Aggregation, interpretability and resource costs / تجميع التنبؤات والتفسير وتكلفة الموارد

Classification aggregation can select the most frequent predicted label; ties require a stated policy. Regression averaging takes the arithmetic mean of predicted numbers. Neither operation proves that individual errors cancel. A small decision tree is often easier to inspect than an entire forest, but tree size matters. Training and storing many trees usually costs more than one comparable tree. Ordinary threshold trees generally do not need scaling merely to compare an ordered feature with a threshold; the surrounding pipeline can still require preprocessing. Missing-value support depends on the implementation and data. Forests are not immune to outliers or overfitting, and higher accuracy must be measured rather than asserted.

قد يختار تجميع التصنيف الوسم الأكثر تكراراً؛ ويحتاج التعادل إلى سياسة محددة. يأخذ متوسط تنبؤات الانحدار المتوسط الحسابي للأعداد. لا تثبت أي عملية إلغاء الأخطاء الفردية لبعضها. تكون شجرة صغيرة غالباً أسهل فحصاً من غابة كاملة، لكن حجم الشجرة مهم. يكلف تدريب أشجار كثيرة وتخزينها عادة أكثر من شجرة مماثلة واحدة. لا تحتاج أشجار العتبات العادية غالباً إلى التحجيم لمجرد مقارنة ترتيب سمة بعتبة؛ وقد تظل المعالجة لازمة في المسار المحيط. يعتمد دعم القيم المفقودة على التنفيذ والبيانات. ليست الغابات محصنة من القيم المتطرفة أو فرط التكيّف، ويجب قياس تحسن الدقة بدلاً من افتراضه.

## U44 — Arithmetic and a minimal implementation route / الحساب ومسار تنفيذ مصغّر

Ratios require a named denominator; percentages multiply a ratio by 100. A weighted mean uses weights that match the question, while the harmonic mean of positive a,b is 2ab/(a+b), not (a+b)/2. Count rows and columns before writing code. A minimal scikit-learn route is to create aligned X and y arrays, split them together, fit KNeighborsClassifier(n_neighbors=3) on the training pairs, predict on held-out inputs, and compare those predictions with held-out labels using accuracy_score. Ensure at least three training examples for this neighbor count. Python and library syntax are an implementation setting, not mandatory prerequisites for manually calculating a distance, Bayes score or confusion-matrix fraction.

تحتاج النسبة إلى مقام مسمّى، وتحولها إلى نسبة مئوية بضربها في 100. يستخدم المتوسط الموزون أوزاناً تناسب السؤال، بينما المتوسط التوافقي لقيمتين موجبتين a,b هو 2ab/(a+b) وليس (a+b)/2. نعد الصفوف والأعمدة قبل كتابة الكود. يبدأ مسار مصغّر في scikit-learn بإنشاء X وy متحاذيتين وتقسيمهما معاً، ثم تدريب KNeighborsClassifier(n_neighbors=3) على أزواج التدريب، والتنبؤ بمدخلات محجوزة، ومقارنتها بوسومها باستخدام accuracy_score. يجب توفر ثلاثة أمثلة تدريب على الأقل لهذا العدد من الجيران. Python وصياغة المكتبة سياق تنفيذ، وليستا متطلبين إلزاميين لحساب مسافة أو درجة بايز أو نسبة من مصفوفة الالتباس يدوياً.
